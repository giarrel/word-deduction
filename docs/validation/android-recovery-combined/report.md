## Observations and limits

Every acceptance image listed above was opened and visually inspected. Early captures sometimes showed the preceding frame or an Android gesture animation despite successful input; later views, actual file state and system logs were used to resolve those cases. One cold-start pause ignored several synthetic Abandon presses, while Resume worked; Home/return restored normal abandonment. A second cold-start attempt after five seconds also ignored the first central Abandon press; a later press on the left side worked. The later EN Back→Abandon→Back sequence also worked. This remains an open ticket 7 investigation; do not claim this gate fully accepted or measured latency. Images 28–31 preserve the narrowed observations.

The large default scrollbar, sparse card layout, verbose White instructions, misleading wrong-guess continuation label in a terminal case, small-display touch sizes and non-Latin font findings still belong to ticket 8. Error copy suggests freeing storage even though this injected failure was a blocked path; a more general retry message would be more accurate. No user data was lost, secret leaked or rule result corrupted in the executed gate. No physical handoff, real group enjoyment, final TalkBack behavior or release packaging has been proved here.
