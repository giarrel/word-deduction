# UI polish / issue 8 — work in validation

## Intent and scope

Preserve the accepted Session, persisted group/match and private-card interaction contracts while making the pass-phone interface rounder, clearer and accessible through public menus. Root owns Android operation; this worktree owns one explicit Unity Editor. No online service or new UI framework was introduced.

## Changes

- Real Android density defines UI units, so a 48-unit control is 48dp. Language buttons now meet that minimum. Shared thin scrollbars keep the list and choices readable.
- Handoff uses a balanced rounded card and original two-card mark; release still clears secret text synchronously before visual settling. Private motion follows Android animator enablement at startup/resume. Menu copy is concise and bilingual, and saved-data failures describe retry without asserting storage as the only cause.
- Public phase prose scrolls when needed. OS text preference scales public text from100% to150%, with nonessential hints omitted at larger sizes and a compact card arrangement. Higher OS scales use this deliberate upper bound; no claim of unconstrained200% text support. Android keyboard and small-screen large-text verification remain a native gate.
- Explicit Unity accessibility hierarchy contains public labels and actual actions. Secret card contents and decorative glyphs are excluded. Text entry focuses the existing field, buttons dispatch the existing rendered submit route. Visibility and clipped frames follow the current layout without rebuilding the hierarchy for keyboard/scroll geometry.
- ATG plus ICU preserves whole-string shaping. Installed script fonts are loaded lazily for saved and draft names, with a cached on-demand route for other installed scripts. This is device-dependent installed-font coverage, not a promise of every Unicode glyph on every OEM.
- A pinned Google Noto Color Emoji CBDT/CBLC font is bundled with its OFL notice because the actual Android16 installed COLRv1 font loaded but rendered blank. The original primary Inter remains in use. Both simple and joined skin-tone emoji are visible in the Editor; Android verification remains separate.
- Unicode name handling is the independently reviewed `f65ec717...` contribution, cherry-picked as `f1e0fd8`: pinned Unicode17 extended graphemes, new blank/invisible rejection and old V4 compatibility. See `../unicode-names/report.md`. Initial badges use the same public first-element helper.
- Original launcher icon is reproducibly generated by `tools/generate-app-icon.ps1`, matching the card mark. Ordinary Android bars replace immersive first-use coaching; native inset/back verification remains a gate.
