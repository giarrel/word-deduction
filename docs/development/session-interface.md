# Session interface

`game/Assets/WordDeduction/Session` is the deep, Unity-independent module for the saved group. Callers open `Session.Open(directory, initialLanguage)`, issue a user action, then obtain `Session.View`. UI code never changes persistent DTOs. View instances are detached copies. The initial locale applies only when no saved state exists.

Actions: add, rename, set participation, remove, undo the last removal, select language/mode, and explicitly start fresh after unrecoverable damage. `CommandResult.Success` means the complete state was saved before the in-memory state changed. `Error` and `Notice` are stable localization keys, not text for direct display. A failed save leaves previous memory and disk intact and can be retried. Invalid/stale player IDs are rejected.

Names are trimmed and NFC-normalized, 1–24 Unicode text elements, without control characters. Stable IDs are independent of names. Duplicate names retain durable numeric disambiguators; entering a name equal to a generated label is also disambiguated. Twenty people may be active; additional saved people begin paused, with `AddedPaused`. Forty people may be saved. Undo restores identity, order and participation unless a current capacity limit prevents it.

The JSON envelope has `Version`, `Payload` and SHA-256 `Checksum`. Both checksum and group invariants are validated. Each write flushes a pending file, then atomically replaces primary and previous generation. Pending files are never treated as confirmed actions. A damaged primary may recover a valid previous generation; the view exposes `RecoveredBackup`. Both invalid generations block mutation and expose `DamagedData`; explicit fresh start first archives the damaged files. A newer schema exposes `NewerVersion` and cannot be reset by this app. Read permission/IO errors expose `ReadFailed` without overwriting files.

Android uses the application's internal files directory; the Editor uses a dedicated subdirectory of Unity's `persistentDataPath`. `link.xml` preserves the JSON DTOs for IL2CPP. The serializer is Unity's `com.unity.nuget.newtonsoft-json` package. The .NET behavior runner compiles the same source and references that exact resolved Newtonsoft DLL. By default, run Unity's initial import first; an already resolved DLL from another checkout can instead be passed with `-p:NewtonsoftJsonAssembly="<absolute path to Runtime/Newtonsoft.Json.dll>"`. This overrides only the reference path, not the production sources under test.

`ReadyToStart` describes group-size validity. Quick and Classic share `StartMatch`, private reveal/conceal/advance, clue-round voting, confirmation, result and rematch actions. The Session owns all rules; presentation reads the detached `Match` view and never computes winners.

Classic adds saved `WhitePreferred` and effective group counts, `Match.Survivors`, `Round`, an eliminated role in `Elimination`, and `ContinueRound(expectedRound)` / `ResolveWhiteGuess(expectedParticipantId, correct)`. No private words appear in ordinary views or elimination/guess screens. `RevealWord` deliberately returns `Mr. White` only for that private role card; the UI supplies its localized bluffing instruction. The role's guess is spoken and judged by the group, never compared as typed text.

The V3 envelope retains V1 groups and V2 frozen Quick deals. Missing progress fields default to round 1 with no eliminated participants. Existing phase values 0–3 retain their meaning; Elimination 4 and WhiteGuess 5 are appended. Opening old data does not write or redraw. All writes still use the same atomic transaction. Newer versions remain blocked before corruption recovery.

`Result.WinningRoles` is the complete winning set. A correct White guess yields only White; one surviving Civilian yields the roles of living adversaries (Undercover, White, or both). `Winner` remains the first role for Quick-compatible callers; multi-role presentation must use `WinningRoles`. Pending White guesses are persisted before any terminal check. Eliminations affect the frozen match only, leaving the saved group's participation untouched.
