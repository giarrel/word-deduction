# Actual Android store screenshots

Ten unchanged full-frame PNGs from the installed **1.0.0/code4** local nondevelopment APK. The coordinator personally inspected each during real play. These are native emulator captures of the production UI, not Editor mockups or generated artwork. No watermark, phone frame, retouching, crop or secret-card compositing was added.

The [provenance manifest](provenance.json) gives exact clean source pin, APK hash, original capture path, dimensions and SHA256. Device: owned API36 AVD,1080×1920/density480, ARM64 translated on x86_64; its camera cutout and navigation surface are retained. Dummy test groups were entered/played locally. Some views are scrollable; a captured viewport does not represent all saved names or result rows.
